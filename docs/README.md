# Herakles Documentation

Herakles documentation is split by job so the same decision is not explained in multiple places.

- [Quick Start](quick-start.md): initialize a workspace, add projects, run the UI, and run automation.
- [Architecture](architecture.md): product model, workspace structure, UI/API boundary, and automation model.
- [Code Style](code-style.md): source ownership, naming, config writes, testing shape, and UI implementation rules.
- [Tooling](tooling.md): Bun commands, formatting, linting, type checks, Fallow, and GitHub Actions.
- [Deployment](deployment.md): current source-run deployment model, local cron, generated state, and release status.
- [Decision Records](adr/): immutable architecture decisions.

Use `CONTEXT.md` as the language guide for product terms.
