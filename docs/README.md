# Herakles Documentation

Herakles documentation is split by job so the same decision is not explained in multiple places.

- [Quick Start](quick-start.md): initialize a workspace, add projects, and spin it up.
- [Architecture](architecture.md): product model, workspace structure, and CLI surface.
- [Code Style](code-style.md): source ownership, naming, config writes, and testing shape.
- [Tooling](tooling.md): Bun commands, formatting, linting, type checks, Fallow, and GitHub Actions.
- [Deployment](deployment.md): current source-run deployment model, generated state, and release status.
- [fix-path plugin](plugins/fix-path.md): move a hosted clone to its canonical path.
- [Sync plugin](plugins/sync.md): the bundled `projects sync` plugin and its stash handling.
- [prs plugin](plugins/prs.md): review open pull requests from the terminal.
- [Decision Records](adr/): immutable architecture decisions.

Use `CONTEXT.md` as the language guide for product terms.
